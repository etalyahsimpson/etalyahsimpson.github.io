## Interaction contract

- Featured project title, brand visual, and `Explore case study` open the internal
  static route; the URL bar updates and the page shares independently.
- `View repository`, the GitHub badge, and the GitHub icon open the correct
  external repository in a new tab (`target="_blank" rel="noopener noreferrer"`).
- Every project page exposes `Copy Project Link`, which copies
  `https://etalyahsimpson.github.io/projects/<slug>/` with a polite confirmation
  and a manual fallback if the Clipboard API is unavailable.
- Browser Back/Forward works normally; breadcrumbs return to `/projects/` or `/`.
